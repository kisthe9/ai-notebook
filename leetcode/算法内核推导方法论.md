# 算法内核推导方法论

> 一套与具体题目、语言、领域无关的推导流程。目标：把「解出一道题」升级为「遇到任何一类题都能推出解」。
>
> 核心命题：**推导的产物不是答案，是一条「约束 → 不变量 → 裁剪 → 下界」的因果链。** 会做一百道题，不如会重复走这一条链。

---

## 一、三层认知模型

任何问题的信息都分三层，能力差距只体现在你停在哪一层。

| 层 | 内容 | 检验方式 |
|---|---|---|
| **表象层** | 题面故事、变量名、应用领域 | 换个说法就懵 |
| **结构层** | 约束的**形状**：是否有序/有界/可分解/有最优子结构/有无保证 | 换故事能做，换约束又崩 |
| **原理层** | 一句**不变量** + 解的合法性证明 + 复杂度下界 | 改任何约束都能立刻判断解是否还成立 |

**判据**：能否一句话说清「我的不变量是什么」「我凭什么排除被丢弃的解空间」。**换皮是表象层扰动，改约束才是原理层扰动**——后者才是真正的掌握检验。刷题刷在表象层，做一百题还是背一百题。

---

## 二、主推导管线：六步降维

固定流程，每步有明确产出物——写不出产出就是没做完。适用于任意问题类。

### Step 1 · 约束归约：把题面翻译成结构

压成 `给定 X，求 Y，满足 Z`，然后逐字审查每个限制词——**每个形容词都是一把解锁结构的钥匙**。常见隐藏约束及其解锁的能力：

- **有序 / 可排序** → 二分、双指针、单调栈、贪心交换论证。
- **值域有界**（哪怕数据规模大）→ 计数/基数排序、bitset、状态压缩。
- **解唯一 / 存在性保证** → 找到一个即可，省去校验与枚举。
- **最优子结构 + 重叠子问题** → DP；若再加**贪心选择性质** → 可退化为贪心。
- **无后效性** → 状态只需保留最少信息，这是「标量替代数组」的前提。
- **单调性**（前缀/窗口随扫描单向变化）→ 剪枝、双指针、单调队列。

**产出**：一张「隐藏约束 → 它解锁的技巧」对照表。某条约束用不上，通常意味着还没读透题面。

### Step 2 · 暴力基线：先造一个可信的参照

无论多慢，先写一个确信正确的解（DFS 枚举 / 多重循环 / 全排列）。它有两个不可替代的用途：**复杂度靶子**（超时是被 `规模 × 每步代价` 算出来的，不是感觉出来的）与**正确性 oracle**（供最终对拍）。

**纪律**：暴力必须**独立手写**，不能从优化解倒推。两者共享同一份误解时，对拍必然「全绿」——那是最危险的安全感。

### Step 3 · 冗余审计：优化不是灵感，是清算重复

逐项盘问暴力解「哪里被算了多次」，每一种重复都对应一类降维手段：

| 暴力在重复什么 | 清算手段（范式） |
|---|---|
| 重复计算同一子问题 | 记忆化 / DP（换空间换时间） |
| 重复扫描区间的累积量 | 前缀和·差分·滚动标量 |
| 重复尝试**已被判死**的候选 | 剪枝 / 贪心裁剪 / 二分答案 |
| 每步重算全局极值 | 堆 / 单调栈 / 滚动极值 |
| 用额外数组记录中间状态 | 原地算法 / 位压缩 |
| 两两比较求关系 | 排序 / 并查集 / 哈希 |

**产出**：优化解的每个变量、每层循环，都能对应「它消灭了暴力里的哪一笔重复」。对应不上，说明引入了无谓复杂度。

### Step 4 · 不变量立法：把解压缩成一句话

固定句式：**「算法推进到某状态时，某个量恒等于 / 恒满足 ___」**（恒满足，不是「大概」）。这句话是解的灵魂，也是所有正确性论证的锚点。

```
（示意）候选法：推进到 i 时，被丢弃的候选已证不可能优于当前候选
（示意）双指针：不变量 = 两指针夹出的区间恰是「尚待检查」的部分
（示意）DP：dp[state] = 子问题 state 的最优值，且该值只依赖更小的 state（无后效性）
```

> ⚠️ **忠于语义，而非命名。**变量没改名不代表含义没变；写不出精确不变量，往往说明你其实不知道这行在干什么。这是最隐蔽的一类腐化，也是「看懂了但写不出」的根源。

### Step 5 · 合法性证明：为「敢排除解空间」背书

任何优化都缩小了解空间。**必须证明被排除的部分不含最优解**——这一步把「猜得快」变成「证得对」，也是复杂度能降下来的真正原因。标准论证工具：

- **交换论证**（贪心主力）：假设最优解不含我的局部选择，证明把它替换成我的选择后**不变差** → 存在一个以我的选择开头的全局最优。
- **反证 + 支配关系**：若某候选被支配（处处不优于另一候选），整段可一次排除。
- **数学归纳**（DP / 递归主力）：基例成立 + 递推保持 → 所有状态正确。
- **单调性论证**（二分 / 双指针）：谓词沿某方向单调，故可安全折半或收缩。

**判据**：能回答「如果这一步排错了，反例长什么样」。答不出，就说明你在执行一个**没被证明的直觉**。

### Step 6 · 复杂度对账 + 下界意识

报出时间/空间，并区分**已消除的代价**与**不可消除的代价**。前者指出还能再优化的方向，后者告诉你「到这里为止，再想更快是错的追求」。

**判断是否到顶的三条下界线索**：
- **信息下界**：是否每个输入元素都至少被"看"了一次？是 → 线性已是极限。
- **决策树/比较下界**：依赖比较的问题常卡在 Ω(n log n)，直到发现可换的信息通道（值域有界 → 计数排序；单调谓词 → 二分）。
- **归约下界**：能规约到已知难题（如 3SUM、图割）的部分，别指望多项式突破。

**产出**：一行「瓶颈定位在 __，已达 __ 界」。

## 三、可复用的降维算子：跨领域原语

**迁移发生在算子层，不在题目层。**题目会过时，算子跟着你换语言、换领域。把每解出的优化归约到某个算子：

| 算子 | 触发信号 | 变换内核 | 失效条件 |
|---|---|---|---|
| **累积压缩** | 答案依赖「一段的聚合」/「自身之外的两侧」 | 用滚动累积量替代每次重算；无逆元运算（如含 0 的乘法、max）改双向扫描 | 聚合不满足结合律（如区间中位数）→ 需线段树 |
| **单调裁剪** | 候选构成有序区间，存在支配关系 | 维护边界标量，一旦越界整段判死，指针跳跃前进 | 候选间无支配关系 → 退回枚举/DP |
| **分治·折半** | 解空间可按谓词单调二分，或问题可独立分解再合并 | 每次排除常数比例空间 | 谓词非单调 / 子问题高度耦合 |
| **记忆化·状态压缩** | 重叠子问题 + 无后效性 | 用空间换重复计算；状态维可压则压 | 有后效性 → 需增加状态维度或换序 |
| **抵消对冲** | 「多数/少数」「成对匹配」「唯一落单」 | 不统计绝对频次，两两对消让过剩者浮现 | 无存在性保证 → 必须补二次校验 |
| **对偶分解** | 整体难解，拆成互不依赖的两半且可合并 | 找分解轴：时间/空间/运算/层次 | 拆完两半仍需来回沟通 = 切错了轴 |

**精髓示例**：为什么「除自身外的乘积」禁用除法仍能做到线性？因为 `0` 没有乘法逆元，除法这条路本质不通——于是**左右两侧各自累积、再相乘**绕开。把「题目刁难」翻译成「代数结构约束」，正是算子思维的价值：**你不是在记技巧，是在识别结构。**

## 四、举一反三：三条有方向的迁移路径

「举一反三」不是联想，是**受控变换**。三条路径强度递增：

- **路径 1 · 参数化泛化**：把解里的魔法常数/维度抽成参数，一族问题塌缩成一个函数。**当标量不变量装不下参数时，就是该升维成数组状态（DP）的信号**——参数化是通往 DP 的前奏。
- **路径 2 · 条件压力测试**（最高价值）：对已解出的题主动改一个约束，看 Step 4 的不变量在哪断裂、需升级到哪种解法。常见断裂规律：**贪心几乎总在「求所有解 / 求最坏情形 / 破坏单调性」时失效，DP 是它的通用兜底**——理解了这点，「该贪还是该 DP」就不再靠猜。
- **路径 3 · 反向出题**：给定一个不变量或算子，构造两道表层故事完全不同、内核相同的题。**能出题才算真懂**，这是最强的自检。

## 五、验证闭环（防止「推导」沦为「猜想」）

方法论的价值一半在推导，一半在**证明推导没错**。四件硬流程：

1. **双 oracle 对拍**：优化解与暴力解比结果；非平凡答案还要**独立验证可行性**（同族可能多解，逐值相等会误报）。
2. **不变量断言**：把 Step 4 那句话变成每步的 assert，比断言最终结果更早暴露 bug。
3. **边界清单**：空/单元素/全相同/极值/含 0 与负/参数越界/无解/多解——写解前逐条过。
4. **规模实测**：理论复杂度 ≠ 跑得动，用真实最大规模验证一次常数。

**通用防线**：发现不一致时**先审 oracle，再动被测代码**——参照系也是代码，也会错；最阴险的 bug 不报错，只给出「看着合理」的错误值。

## 六、元层：知识如何被压缩与检索

**每题只记一条四拍因果链**，格式固定：

```
隐藏约束 → 不变量 → 排除依据（合法性证明）→ 复杂度下界
```

四拍写不全，说明推导没走完。存这一句话，比存一百行代码更抗遗忘。

**三级压缩体系**：
- **L1 题解**——单个实现（一道题）
- **L2 范式索引**——题 → 范式的映射表（一类题）
- **L3 变换算子**——本文件第三章的跨领域原语（普适）

做题时从 L1 提炼到 L3，遇新题时从 L3 回落到 L1。**只在 L1 积累 = 背题；能在 L3 自由回落 = 掌握。** 日常笔记应把每道新题**先归类到已有算子**，只有出现新算子时才扩表——让知识库按「算子」而非「题量」增长。
